# Clawmasutra design

Manuscript night. Not a purple dating-app clone.

- Ground: `#14090c`
- Blood: `#7a1f2e`
- Candle: `#f4e6d0`
- Gold: `#c9a36a`
- Type: Fraunces for titles, Instrument Sans for UI
- Mark: a claw that is also a closed loop, gold stroke
- Cards: hairline panels, large serif names, one photo, one reason
- Motion: none that performs. Instant state change on swipe.

Copy is short and adult. No “spark”, “journey”, or “AI-powered”.
